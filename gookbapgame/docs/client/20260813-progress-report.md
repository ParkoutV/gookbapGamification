# 게임 클라이언트 진행 보고

**기간** 2026년 8월 9일 ~ 8월 12일
**범위** 게임 클라이언트 — 대시보드·서버는 별도

---

## 1. 방문자 통계 복구 — 가장 시급했던 건

**접속 로그가 기록되지 않던 구간이 있었고, 8월 10일에 교체했습니다.**

서버 측에서 접속 로그 기록 방식을 세션 기반으로 개선하면서 기존 경로가 차단되었는데, 게임 클라이언트가 옛 방식으로 계속 기록을 시도하고 있었습니다. 이 기록은 실패해도 게임 진행을 막지 않도록 설계되어 있어, **오류 없이 조용히 누락**되었습니다.

> 해당 구간의 대시보드 수치가 실제로 어떻게 남아 있는지는 확인이 필요합니다.

새 방식으로 교체하고 로컬 환경에서 직접 검증했습니다(연속 접속 시 중복 미집계, 세션 만료 시 신규 기록).

함께 배선한 지표:

| 지표 | 상태 |
|---|---|
| 방문자 수 | 복구 완료 |
| 게임 시작 / 재도전 | 신규 연결 |
| 공유 참여 / 공유 유입 | 신규 연결 ('친구 초대하기' 버튼 추가) |
| 설문 완료 · 쿠폰 발급 | 기존 유지 |

> **참고 — '방문자 수'는 순 방문자가 아니라 접속 횟수(PV) 기준입니다.**
> 같은 분이 여러 번 접속하면 그만큼 늘어납니다. 대시보드 수치를 읽으실 때 참고 부탁드립니다. 순 방문자 수가 필요하시면 동일 데이터로 산출 가능합니다.

**'친구 초대하기'** — 시작 화면에 추가했습니다. 현재 주소를 복사하는 방식이 아니라, 같은 지점의 공유 전용 링크를 실어 보냅니다. 매장 QR 주소를 그대로 복사하면 유입이 공유로 분류되지 않기 때문입니다.

## 2. 쿠폰 발급 신뢰성

발급 제한이 1일 1회에서 3회로 완화되면서 드러난 문제 2건을 수정했습니다.

- **이미 받은 쿠폰이 새로 당첨된 것처럼 다시 표시되던 문제** — 며칠 전 받아둔 쿠폰이 당첨 연출·효과음과 함께 매번 새 쿠폰처럼 나타났습니다. 방금 발급된 쿠폰만 표시하도록 좁혔습니다.
- **설문을 마친 분에게도 '설문하고 쿠폰 받기' 버튼이 남아 추가 발급되던 문제** — 이 버튼은 설문 안내를 거절한 분을 위한 재진입 경로인데 조건이 누락되어 있었습니다.

**뽑기 대기 화면**도 2단계로 나눴습니다. 이전에는 결과를 알기 전부터 "카드를 섞고 있어요"가 떠서, 발급 조건에 해당하지 않는 분께도 기대를 갖게 했습니다.

## 3. 첫 접속 속도 — 전송량 660KB 절감

로딩 화면 추가를 검토하다 먼저 실측했고, 화면을 만드는 대신 원인을 줄이는 쪽이 낫다고 판단했습니다.

| 항목 | 이전 | 이후 |
|---|---|---|
| 픽셀 폰트 | 505KB | 77KB |
| 배경음악 | 240KB (재생 전 선다운로드) | 재생 시점에 로드 |

첫 화면 전송량의 55%가 폰트였습니다. 게임에서 실제 쓰는 글자만 추리되, 3개 언어 문구와 향후 추가분까지 여유 있게 포함했습니다.

## 4. 다국어 — 한국어 · 영어 · 일본어

- **닉네임이 어떤 언어를 선택해도 한국어로 표시되던 문제**를 수정했습니다. 화면에서 언어를 바꾸면 닉네임도 즉시 따라옵니다.
- 번역이 채워지지 않은 단어가 있으면 **한 닉네임 전체를 한국어로** 표시합니다. 앞말만 번역된 경우 "Hearty 국밥"처럼 두 언어가 섞이기 때문입니다.

## 5. 실기기 대응 (iOS · Android)

데스크톱에서는 재현되지 않아 실제 기기 제보로 확인된 건들입니다.

- **게임 화면이 잘려 스크롤해야 플레이 가능하던 문제** — 브라우저 하단 툴바 두께만큼 화면이 넘쳤습니다. 툴바를 포함한 실제 높이를 쓰도록 전환했습니다.
- **시작 시 효과음이 여러 개 동시에 울리던 문제, 버튼 소리 지연** — iOS의 음량 제어 방식 차이가 원인이었습니다. 재생 방식을 전면 교체했습니다.
- **"GAME OVER" 등 연출 글자가 창 밖으로 넘치던 문제** — 글자 폭을 실제로 측정해 맞추는 방식으로 바꿨습니다.

## 6. 화면 · 연출

디자인 톤을 90년대 데스크톱 UI 컨셉으로 통일하고, 게임 화면을 폴라로이드 액자 형태로 개편했습니다(단계 표시, 남은 시간 칸 게이지, 문항 진행 표시). 시작·종료 연출과 배경음악·효과음도 추가했습니다. 음소거 설정은 매장·공공장소를 고려해 기기에 저장됩니다.

쿠폰 카드의 날짜 표시도 확장했습니다 — **현재 발급일·사용기한 2줄이며, 시작일은 아래 연동 후 3줄이 됩니다.**

*화면은 시연으로 보여드리겠습니다.*

## 서버 측과 연동 예정

기능은 구현되어 있고, 데이터가 연결되면 코드 수정 없이 반영됩니다.

| 항목 | 현재 | 연결 시 |
|---|---|---|
| 쿠폰 시작일 | 발급일·사용기한 2줄 표시 | 3줄로 자동 확장 |
| 닉네임 영어·일본어 번역 | 번역이 없으면 한국어 표시 | 선택 언어로 자동 표시 |
| 뽑기 잔여 횟수 안내 | 미표시 | 조회 경로 확보 후 반영 |
