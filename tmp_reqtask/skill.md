# 프로젝트 기술 스택 및 개발 가이드 (Project Tech Stack)

이 문서는 국밥 게이미피케이션(Gookbap Gamification) 프로젝트의 기술 스택 및 주요 요구사항을 정의합니다. 에이전트 및 개발자는 이 문서의 지침을 따라 코드를 작성해야 합니다.

## 1. 프론트엔드 및 백엔드 (Frontend & Backend)
- **프레임워크**: Next.js (App Router 기반)
- **패키지 매니저**: npm
- **설명**: Next.js를 사용하여 클라이언트 UI(프론트엔드)와 API Route/Server Actions(백엔드 로직)를 하나의 프로젝트에서 통합 개발합니다.

## 2. 데이터 저장소 (Data Storage)
- **종류**: 브라우저 LocalStorage
- **설명**: 별도의 데이터베이스 서버나 파일 DB(SQLite 등)를 구축하지 않고, 사용자의 브라우저에 내장된 LocalStorage를 활용하여 데이터를 저장합니다. 서버 구축 및 유지보수 비용을 완전히 없애고 데이터를 클라이언트에서 가볍게 관리합니다.

## 3. OCR (광학 문자 인식)
- **처리 환경**: 로컬 (Local)
- **추천 라이브러리**: `tesseract.js`
- **설명**: 영수증이나 이미지에서 텍스트를 추출하는 작업은 외부 API를 사용하지 않고 로컬 환경(클라이언트 브라우저 또는 Node.js 서버)에서 직접 처리합니다.

## 4. LLM (대규모 언어 모델)
- **처리 환경**: 외부 LLM API
- **추천 모델 및 서비스**:
  1. **Google Gemini API**: 뛰어난 텍스트 추론 및 멀티모달(이미지 인식 등) 기능을 제공하며 가장 권장하는 방법입니다.
  2. **Google Colab**: 무료 GPU를 활용하여 오픈소스 모델(예: Gemma, Llama 등)을 호스팅하고, ngrok이나 localtunnel 등을 통해 Next.js 서버에서 API로 호출하여 사용할 수 있습니다.
  3. **OpenAI API**: 안정적이고 대중적인 대안입니다.
- **설명**: OCR로 추출된 텍스트 데이터를 분석하거나 사용자 맞춤형 피드백/게이미피케이션 요소를 생성할 때 사용합니다.

---

### ⚠️ 보안 및 환경 설정
- **환경 변수**: LLM API Key 등 민감한 정보는 반드시 `.env.local` 파일에 저장하고 `.gitignore`를 통해 버전 관리에서 제외해야 합니다.
- **API 호출**: 외부 LLM API 호출은 보안을 위해 클라이언트 사이드가 아닌 Next.js의 서버 사이드(API Route 또는 Server Component)에서 수행해야 합니다.
