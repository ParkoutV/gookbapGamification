# LLM을 활용한 영수-증 관리 및 웹 호스팅 시스템 구축

이 프로젝트는 사용자가 영수증 이미지를 업로드하면, LLM(대규모 언어 모델)을 통해 구매 내역, 가격, 시간 등의 데이터를 자동으로 추출 및 저장하고, 이를 웹 페이지에 시각화하여 보여주는 시스템을 구축하는 것을 목표로 합니다.

---

## 단계별 실행 계획

### 1. 데이터 관리: 브라우저 `LocalStorage`를 활용한 클라이언트 스토리지 구성

-   **목표**: 서버 비용 없이 사용자의 브라우저에 구매 내역 데이터를 가볍고 빠르게 저장하고 관리합니다.
-   **실행 방안**:
    -   별도의 백엔드 데이터베이스(SQLite 등)를 구축하지 않고, 클라이언트 단에서 브라우저의 `LocalStorage` API를 직접 활용합니다.
    -   영수증에서 추출된 구매 내역(항목, 가격, 구매 시간) 데이터를 JSON 형태로 직렬화하여 LocalStorage에 저장하고 관리합니다.
    -   상태 관리 라이브러리(Zustand 등)와 연동하여 LocalStorage의 데이터를 화면에 즉각적으로 반영할 수 있도록 설계합니다.

### 2. 데이터 추출: `Ollama` 기반 LLM을 이용한 이미지 분석

-   **목표**: 영수증 이미지에서 텍스트를 인식하고, 정해진 형식(구매 내역, 가격, 시간)에 맞춰 데이터를 구조화합니다.
-   **실행 방안**:
    -   로컬 또는 서버 환경에 `Ollama`를 설치하고, LLaVA와 같이 이미지 분석이 가능한 멀티모달 모델을 준비합니다.
    -   백엔드 서버에서 사용자가 업로드한 이미지를 수신할 때, **업로드된 파일이 HEIC이든 JPG이든 상관없이 모두 `WebP` 포맷으로 자동 변환(최적화)하는 이미지 전처리 시스템을 구현합니다.** 이를 통해 저장 공간을 절약하고 LLM 처리 속도를 높입니다.
    -   WebP로 변환된 이미지를 Ollama의 API로 전달하는 로직을 구현합니다.
    -   LLM에 "이미지에서 구매한 모든 상품명, 각각의 가격, 그리고 구매 날짜와 시간을 추출해서 JSON 형식으로 정리해줘" 와 같은 프롬프트를 전송하여 정제된 결과값을 받습니다.
    -   Ollama로부터 받은 JSON 데이터를 파싱하여 1번 단계에서 설계한 브라우저의 `LocalStorage`에 저장합니다.

### 3. 번역 기능: 경량 모델을 이용한 다국어 지원

-   **목표**: 추출된 구매 내역을 다른 언어로 번역해야 할 경우, 빠르고 효율적인 번역 기능을 구현합니다.
-   **실행 방안**:
    -   `Ollama`를 통해 ArgosTranslate와 같은 가벼운 번역 모델을 구동하거나, 특정 언어 번역에 특화된 소규모 라이브러리를 활용합니다.
    -   필요시, "이 텍스트를 영어로 번역해줘" 와 같이 간단한 요청을 처리하는 별도의 API 엔드포인트를 백엔드에 구축합니다.

### 4. 웹 호스팅: `Vercel`을 이용한 간편한 배포

-   **목표**: 사용자가 쉽게 접근하고 상호작용할 수 있는 웹 애플리케이션을 개발하고, 이를 안정적으로 인터넷에 배포합니다.
-   **실행 방안**:
    -   Next.js 또는 React와 같은 프레임워크를 사용하여 사용자 인터페이스(UI)를 개발합니다. 이 UI에는 파일 업로드 기능과 데이터 조회 화면이 포함됩니다.
    -   개발된 프로젝트를 GitHub 저장소에 연결합니다.
    -   Vercel 플랫폼에 해당 GitHub 저장소를 연동하면, 코드 변경사항이 생길 때마다 자동으로 빌드 및 배포가 이루어져 운영 부담이 크게 줄어듭니다. 백엔드 API는 Vercel의 서버리스 함수(Serverless Functions)를 통해 손쉽게 배포할 수 있습니다.
