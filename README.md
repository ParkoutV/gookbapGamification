# 1953 형제돼지국밥 게이미피케이션 프로젝트 (Gookbap Gamification)

이 저장소는 오프라인 매장 방문객 및 온라인 유입 사용자들을 위한 **게이미피케이션 웹 게임(틀린그림찾기)**과 이를 관리하고 데이터를 분석하는 **관리자 대시보드**를 포함하는 통합 프로젝트입니다.

본 프로젝트는 크게 두 가지 핵심 모듈로 구성되어 있습니다.

## 1. 웹 게임 클라이언트 (`gookbapgame`)
앱 설치나 회원가입 없이 오프라인 매장의 QR 코드나 온라인 공유 링크를 통해 즉시 접속하여 즐길 수 있는 틀린그림찾기 웹 게임입니다.

- **기획 및 디자인 컨셉**: 90년대 데스크톱 UI와 픽셀 아트 기반의 레트로(뉴트로) 감성을 채택하여, 젊은 층과 중장년층 모두에게 친숙하게 다가가며 모바일 환경에서의 초기 로딩 성능을 극대화했습니다.
- **주요 흐름 (User Flow)**: `튜토리얼 → 틀린그림찾기 7단계 → 결과 및 랭킹 → 설문조사 → 뽑기(가챠) → 온/오프라인 쿠폰 보관함`
- **게임성**: 배경 이미지 위에 무작위로 파츠(오브젝트)를 조합하고 정답 위치를 섞어, 동일한 배경이 나와도 매판 새로운 문제처럼 느껴지도록 설계되었습니다.
- **글로벌 대응**: 방문객을 위해 한국어, 영어, 일본어, 중국어(간체) 등 다국어를 완벽하게 지원합니다.

## 2. 관리자 대시보드 (`gookbapanalyze`)
웹 게임에서 발생하는 모든 데이터를 실시간으로 수집하고, 게임 내 콘텐츠를 동적으로 제어하기 위한 통합 관리 시스템입니다. 본사(Admin)와 각 가맹점(User) 권한이 철저히 분리되어 운영됩니다.

- **실시간 KPI 모니터링**: 방문자 수, 게임 완주율, 설문 완료율, 쿠폰 발급 및 사용률 등을 지점별/유입경로별로 정밀하게 추적합니다.
- **오프라인 쿠폰 스캐너**: 매장 직원이 기기 카메라로 유저의 쿠폰 QR을 직접 스캔하여 안전하게 사용 처리할 수 있는 다국어 지원 전용 스캐너를 제공합니다.
- **퍼즐 비주얼 에디터**: 게임에 노출되는 틀린그림찾기 파츠들을 웹 브라우저 상에서 직접 드래그 앤 드롭으로 배치하고, 크롭 및 1px 단위의 정밀 보정을 수행할 수 있는 강력한 편집기를 내장하고 있습니다.
- **동적 제어 시스템**: 설문조사 문항, 룰렛 당첨 확률 및 구간 분배, 대량 엑셀 쿠폰 업로드, 다국어 텍스트 등을 개발자의 코드 수정 없이 즉각적으로 반영할 수 있습니다.
